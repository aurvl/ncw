# Outputs

Generated by `python scripts/main.py`. CSV files are canonical.

- `country_level_gcw.csv`, `country_level_ncw.csv`: one row per accounting unit.
- `tables/`: paper tables.
- `validation/`: `global_checks.csv`, `coverage.csv`, `biome_share_comparison.csv`.
- `draws/`: Monte Carlo draw matrices (not versioned).
