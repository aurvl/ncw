# Results

This folder contains outputs prepared for the manuscript and its supplementary material. Reusable analytical intermediates, country-level working accounts, model draws, audit files, Gibbs/GFW products, and Busch reconstruction outputs are written under [`../data/outputs/`](../data/outputs/README.md).

```text
results/
  tables/
    manuscript/       manuscript and supplementary tables, including Manuscript_tables.xlsx
  figures/
    manuscript/       paper figures generated by Notebook 08
    ...               reviewed alternatives and supplementary figures
  archive/            superseded manuscript-facing exports retained for provenance
```

Run `python code/scripts/main.py` from the repository root to rebuild the accounts, analyses, checks, and machine-readable manuscript tables. Notebook 09 runs separately to preview the tables and create `tables/manuscript/Manuscript_tables.xlsx`; Notebook 08 runs separately to create manuscript figure files. The pipeline does not store its intermediate accounts or diagnostics in this folder.

Units and calculation scope are described in [`../docs/METHODS.md`](../docs/METHODS.md) and [`../docs/DATA_SOURCES.md`](../docs/DATA_SOURCES.md).
