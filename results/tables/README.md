# Study Tables

This README describes the study tables and defines their columns and units. The table names and column names below form the data dictionary for the CSV and Excel outputs.

`main.py` generates the ten tables numbered 01–10. Notebook 09 previews and writes `manuscript/Manuscript_tables.xlsx`; it does not change the CSV outputs.

The results are organized by account and analysis:

- The BCW table presents the original blue-carbon account alongside the updated mangrove area, mangrove sequestration, and recalculated account value.
- GCW reports forest areas and sequestration separately for each of the four biomes.
- NCW brings the blue and green accounts together for each harmonized entity.
- Additional outputs describe deforestation, restoration, regional and economic-group profiles, global summaries, spatial-model results, and data coverage.

## Folder structure

```text
tables/                                             # Result tables and their documentation
├── README.md                                       # Definitions and units for every result-table column
├── 01_bcw_hilmi_updated.csv                        # BCW records with selected mangrove areas and updated account fields
├── 02_gcw_by_entity.csv                            # Forest areas, rates, sequestration, and GCW by entity
├── 03_country_level_ncw.csv                        # Integrated country- and territory-level account
├── 04_deforestation_by_entity.csv                  # FRA forest loss and associated lost capacity
├── 05_restoration_costs_by_entity.csv              # Restoration targets, coverage, and costs
├── 06_restoration_supply_curves.csv                # Cumulative restoration supply by price
├── 07_geographic_economic_profiles.xlsx            # Two sheets: Region and Economic group
├── 08_global_accounts_summary.csv                  # Global totals by component and account
├── 09_spatial_model_results.csv                    # Spatial-model estimates, diagnostics, and comparisons
├── 10_results_coverage.csv                         # Coverage of generated result records
├── legacy/previous_exports/                         # Older table exports, no longer generated by main.py
├── manuscript/
│   ├── Manuscript_tables.xlsx                      # Workbook written by Notebook 09
│   ├── temp.txt                                    # Workbook design notes
│   └── Table*.csv, Supplementary_*.csv              # Supporting outputs retained for current analyses
```

GCW and NCW use the same set of entities. A missing value remains blank in a CSV field or workbook cell and is read as NaN; it is not changed to zero in the result table.

## Column-family conventions

In the names below, {biome} takes one of these values: tropical, subtropical, temperate, or boreal. {bce} takes one of these values: saltmarsh, seagrass, or mangrove. {stat} takes one of these values: mean, sd, p05, p50, or p95, when that statistic is calculated.

Forest areas are measured in hectares. Marine ecosystem areas use the units stated in each table: km2 in table 01 and hectares in tables 03 and 07. Physical flows are annualized. Monetary accounts are expressed in constant 2015 US dollars per year. `sd` is the standard deviation across draws, except where the name includes `spatial_sd`, which refers to spatial dispersion in a rate.

## Profile aggregation

In both sheets of `07_geographic_economic_profiles.xlsx`, `n_entities` appears immediately after the profile label. Additive quantities are summed across the entities in each profile. Forest shares, per-capita values, GDP shares, account shares, emissions ratios, and restoration-target coverage are recalculated from profile-level totals rather than averaged across entities. For fields with `{stat}`, corresponding entity draws are summed within each draw before the statistics are calculated. The restoration marginal cost is reported as the median of the entity-level values because it is not additive. A profile sum may cover only entities with a reported value; the final coverage counts show how many entities contribute.

## Statistics and missing values

For monetary accounts based on GSCC draws, {stat} identifies the mean, standard deviation, 5th percentile, median, or 95th percentile when available. sd is the standard deviation across draws, except in a name explicitly marked spatial_sd, which describes spatial dispersion in the rate.

A blank CSV value or workbook cell means the data is unavailable (NaN). Physical sums may use reported components according to the calculation rule; source fields and completeness indicators show which components are missing. A missing value does not mean that the underlying quantity is zero.
