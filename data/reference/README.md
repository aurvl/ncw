# Reference files

Controlled inputs written or validated by the authors, not downloaded:

- `pan_biome_areas.csv`: Pan et al. (2024) biome areas (Extended Data Table 1) and published rates per area (Extended Data Table 3), transcribed from the images in `raw/pan/`.
- `territory_crosswalk.csv`: mapping of BCW territories onto the FRA accounting units, with decision, author and date (MYCHOICES C12).
